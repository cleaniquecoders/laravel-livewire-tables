# Development

This section covers everything you need to develop against, and contribute to, the
`cleaniquecoders/laravel-livewire-tables` fork (v4.0 — Laravel 12/13 + Livewire 4). It walks through
installation and local setup, the runnable workbench demo, the Pest test suite, and how to build your
own datatable components.

- [Getting started](01-getting-started.md) — install, requirements, and local development setup.
- [Workbench](02-workbench.md) — the Testbench demo app, how to run and reseed it, and the demo routes.
- [Testing](03-testing.md) — Pest on Testbench, the self-seeding TestCase, and the Flux test coverage.
- [Livewire components](04-livewire-components.md) — build a datatable: columns, filters, search, and themes.
