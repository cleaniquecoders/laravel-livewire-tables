# Requirements

The following are required to use this package regardless of what theme you choose:

- PHP 8.2+
- [Laravel 12.x or 13.x](https://laravel.com)
- [Livewire 4.x](https://livewire.laravel.com)

> Livewire 4 bundles Alpine.js, so you do not need to install Alpine separately. This v4 line
> drops Livewire 3 — stay on the v3 line of the package if you are still on Livewire 3.
